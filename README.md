# projeto_aoc

# Arquivos

- moving_player.asm: Programa que renderiza os tiles de fundo e apresenta um avatar do jogador que pode ser movido por WASD. A tecla q encerra o programa.

- background8.asm/background16.asm: Programas que renderizam os tiles de fundo com o sprite de grama. Ambos tem 16x16 tiles, porém o primeiro tem tiles de 8x8 unidades e o segundo, 16x16.

- conversor.py: Recebe uma imagem png e gera um arquivo em assembly mips com a matriz de pixels. Necessita de um arquivo de paleta de cores no formato gimp.



---

- Site para fazer os sprites: [Piskel](https://www.piskelapp.com/)
