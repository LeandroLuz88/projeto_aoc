# Projeto X

O **Projeto X** é um jogo no estilo *Tower Defense* desenvolvido em Assembly MIPS. No jogo, o jogador controla um personagem que precisa defender o fim do trajeto contra invasões de monstros.

## Funcionalidades Principais

* **Controle do Personagem:** O personagem é capaz de se movimentar livremente pelo mapa, posicionar torres de defesa e também se posicionar estrategicamente para atuar como uma torre.
* **Sistema de Melhorias (Upgrades):** As torres e o personagem principal podem ser melhorados utilizando moedas coletadas. Os upgrades permitem aumentar:
  * Cadência de tiro
  * Poder de ataque
* **Inimigos (Monstros):** Os monstros `m` possuem diferentes níveis de dificuldade e pontos de vida (HP). Quanto maior o desafio do monstro, maior a quantidade de ouro deixada ao ser derrotado.
